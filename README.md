

# SomaShare

## Project Description
SomaShare is a textbook marketplace platform where students can list, buy, and sell textbooks. The system includes offers, transactions, reviews, and user trust scoring.

## Technologies Used
- ASP.NET Core Blazor
- Entity Framework Core
- SQL Server
- C#
- Bootstrap

## Setup Instructions
1. Clone the repository
2. Open solution in Visual Studio
3. Restore NuGet packages
4. Run database migrations:
   - dotnet ef database update
5. Run the application

## Database Design
- Users
- Textbooks
- Offers
- Transactions
- Reviews
